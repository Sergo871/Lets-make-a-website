# Кафе-бар «Авеню» — demo site

Site demo pentru cafe-barul „Авеню” (str. Lenin 20A, Tighina/Bender). O singură pagină, fără build: deschide `index.html` sau urcă folderul `avenue/` pe Netlify / Cloudflare Pages. Limba implicită: rusă, cu buton RU/RO.
