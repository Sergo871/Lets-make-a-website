# Кафе «Авеню» — demo site

Site demo pentru Cafe „Авеню” (str. Lenin 20a, Tighina/Bender). O singură pagină, fără build: deschide `index.html` sau urcă folderul `avenue/` pe Netlify / Cloudflare Pages.

## Date reale (de pe Google Maps)
- Adresă: ул. Ленина 20а, Бендеры
- Telefon: +373 552 78 887
- Program: zilnic 10:00–00:00
- 573 recenzii pe Google, Instagram @avenue_bendery

## De înlocuit înainte de a-l arăta clientului
- **Pozele** din `img/` sunt stock CC0 (vezi `img/CREDITS.json`), nu ale cafenelei. Înlocuiește-le cu pozele lor de pe Instagram, păstrând aceleași nume de fișiere.
- **Meniul** e orientativ (preparate tipice, fără prețuri). Înlocuiește-l cu meniul real.
- Textul „Despre noi” e scris generic.

Limbi: rusă (implicit) și română, cu buton RU/RO.
